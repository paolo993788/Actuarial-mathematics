# Script

Crea una sottocartella per ogni progetto, per esempio `scripts/nome_progetto/`. Inserisci il codice e un README basato su [questo modello](../docs/modello-script.md).

Il README del progetto deve indicare linguaggio e versione, dipendenze, comando di esecuzione dalla radice del repository, input ed output attesi. Per progetti con più file, mantieni le dipendenze accanto al relativo codice.

Aggiungi il progetto al catalogo nel [README principale](../README.md). Questa cartella non contiene ancora script eseguibili.
